How it works

Three parts I designed and built, each doing one job.

✦

Agentic scripting

A LangGraph agent writes each script, rewrites it when a policy gate fails, fact-checks claims against the paper's text and figures, and pauses for human approval on new formats.

◐

Custom avatar engine

An original anchor character drawn in code. Mouth shapes follow the real audio, it blinks, and it is layered into the video as a transparent overlay. No paid avatar service.

↺

Analytics loop

An analytics agent lines up YouTube retention with each spoken sentence. Findings become rules: a short second sentence held viewers far better (median drop 0.21 vs 0.59), so scripts now keep it under 20 words.
